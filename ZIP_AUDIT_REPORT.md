## Fixed during audit

### 1. Missing worker build service

Problem:

`apps/worker/src/app.ts` imported:

```ts
./services/build/local-build-execution.service.js
```

but the source file was missing. This would break worker typecheck/build.

Fix added:

```text
apps/worker/src/services/build/local-build-execution.service.ts
```

The added service performs safe build-profile detection and persists a `BuildProfile` + `BuildRun` as `NOT_ASSESSED` instead of fabricating compiler/test output.

### 2. Runtime TDZ issue in security OS routes

Problem:

`read`/`write` permission middleware constants were used before declaration in:

```text
apps/api/src/modules/security-os/security-os.routes.ts
```

Fix:

Moved `read` and `write` declarations above first usage.
